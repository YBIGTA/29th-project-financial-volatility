## 폴더 구조

```
src/            크롤링·전처리 코드 (git 관리)
data/raw/       원본 크롤링 결과 csv (git 미포함, Drive로 관리)
data/processed/ 전처리 결과 csv (git 미포함, Drive로 관리)
```

## 데이터 저장 규칙

- **코드는 GitHub, 데이터(csv)는 [Google Drive](https://drive.google.com/drive/folders/1QwUSq6zlkbGRhXws84SHQL-ilTBsXFUY)** — `data/raw`, `data/processed`는 `.gitignore`에 포함되어 있음.
- 크롤링 후 `data/raw`, `data/processed` 안의 csv를 위 Drive 폴더에 그대로 업로드.
- 동시 편집 충돌 방지를 위해 파일명에 날짜·작성자 표기: 예) `board_005930_0815_송지훈.csv`
- 인코딩은 UTF-8(BOM 포함, `utf-8-sig`)로 통일 — 엑셀에서 바로 열어도 한글이 깨지지 않음.

## 실행 방법

```bash
pip install -r requirements.txt
cd src
python run_all.py          # 시세 -> 뉴스 -> 게시판 -> 전처리 전체 실행
# 또는 개별 실행
python crawl_price.py
python crawl_news.py
python crawl_board.py
python preprocess.py
```

뉴스·게시판 크롤러는 **이미 저장된 csv에 새로 수집한 데이터를 id/nid 기준으로 병합**합니다.
즉 매일 한 번씩 실행하면 실제 보유 데이터 기간이 계속 늘어납니다. (아래 참고)

## 데이터 수집 범위의 현실적 한계 (중요)

킥오프 가이드의 "최근 3개월" 크롤링은 **시세(일봉)는 문제없이 가능**하지만,
**뉴스·주주토론방은 네이버 플랫폼 자체가 페이지당 20건 × 최대 100페이지(약 2,000건)로
열람을 막아놔서 소급 조회가 불가능**합니다. 종목별로 게시량이 많을수록 실제로
가져올 수 있는 과거 기간이 짧아집니다. 8/14 최초 수집 결과(누적 전):

| 종목 | 뉴스 소급 기간 (건수) | 게시판 소급 기간 (건수) |
| --- | --- | --- |
| 삼성전자 | 2026-08-10 ~ (1,737건) | 2026-08-13 15:44 ~ (1,989건) |
| SK하이닉스 | 2026-08-09 ~ (1,710건) | 2026-08-13 16:11 ~ (1,990건) |
| 카카오 | 2026-07-06 ~ (2,000건, 상한 도달) | 2026-07-31 ~ (1,974건) |
| 에코프로비엠 | 2026-06-17 ~ (1,588건) | 2026-07-20 ~ (1,979건) |

**그래서 이 크롤러는 매일 실행해서 누적하는 방식으로 설계했습니다.** 삼성전자·SK하이닉스처럼
게시량이 많은 종목은 하루만 지나도 오늘 게시글이 2,000건 제한 밖으로 밀려나 영구적으로
못 가져오게 되므로, **오늘부터 최대한 빨리, 그리고 매일(가능하면 하루 여러 번) 실행하는 게
중요합니다.** (작업 스케줄러/cron 등록을 팀에서 논의해볼 것 — 회의에서 공유 필요)

## robots.txt 확인 결과 (8/14 실측)

| 사이트 | 일반 크롤러 정책 | 비고 |
| --- | --- | --- |
| finance.naver.com | 전면 Disallow | 네이버 자체봇(yeti)만 board.naver 일부 허용, 그마저 `page=` 파라미터는 yeti도 금지 |
| m.stock.naver.com | 전면 Disallow | `/api/news/...` 등 API 경로는 yeti 허용 목록에도 없음 |
| blog.naver.com | 시스템 경로만 제한 | **ClaudeBot 등 AI 학습/RAG 목적 봇은 명시적으로 전면 금지** |
| cafe.naver.com | 전면 Disallow | 예외 없이 모든 봇 차단 |
| finance.daum.net | — | 서비스 자체가 종료됨 (404) |
| tossinvest.com | **`Allow: /`** | 크롤링 허용 — 종목별 커뮤니티 탭 존재, 데이터 API는 추가 조사 필요 |

현재 news_*.csv / board_*.csv는 이 확인 이전에 만든 크롤러로 수집한 것이라 robots.txt와
충돌하는 상태입니다. 계속 이 방식으로 갈지, 대체 수단(네이버 오픈 API 등)으로 옮길지는
팀 논의 후 결정 — README 갱신 예정.
